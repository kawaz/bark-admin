# 管理 UI のデザイン

bark-admin の画面の見た目と、その判断。各画面に何を置くかは [../DESIGN.md](../DESIGN.md) の「画面」節。

## コンセプト

- iPhone で片手で触るアプリとして作り、Mac ではそれが横に広がる。タップ対象は 48px 以上、一覧の行は行全体がリンク
- 操作の置き場は画面ごとに 1 か所に集める。TOP は宛先のパネルの下端 (「n 台へ通知を送る」と「デバイスを追加」)、ダイアログは下端の送信ボタン。画面の上端・下端に固定した操作は置かない (散ると目と指が上下に往復する)
- 1 画面に置く物を絞る。TOP は宛先と端末の一覧、詳細は基本情報の表示が主で、操作 (通知を送る・デバイスを追加・確認を送る・暗号化・登録し直す・タグの編集・アーカイブ) はダイアログに出す
- 印象に残す物は 1 つだけ: 通知を送るダイアログの、ロック画面に届く見た目の見本。ほかは静かに保つ

## 色

トークンは `src/ui/style.css` の `:root` の 1 か所で決め、dark は `prefers-color-scheme` で同じ名前を差し替える。

| 名前 | light | dark | 役割 |
|---|---|---|---|
| `--bg` | `#e7ebf2` | `#11162e` | 背景。冷たい霧色 / 夜の紺 |
| `--surface` / `--surface-2` | `#ffffff` / `#f1f3f8` | `#1b2142` / `#252c53` | パネル / 入力欄・チップ |
| `--ink` / `--ink-2` / `--ink-3` | `#18203a` / `#586180` / `#8a91a6` | `#eef0fa` / `#a6adcd` / `#737ba0` | 文字 (本文 / 補足 / 薄い) |
| `--signal` | `#ffc21a` | `#ffc21a` | 通知の黄色。主操作のボタン、今の段、送信先の印、宛先に足したタグだけに使う |
| `--ok` / `--info` / `--warn` / `--danger` | `#17845a` / `#4c4fd0` / `#b25500` / `#c0352b` | `#4cd493` / `#a5a6ff` / `#ffa64f` / `#ff6d60` | 確認済み / 未確認 / 古い / 壊す操作 |
| `--moved` | `#0a72b5` | `#5cb8f2` | 移行済み (青の塗りの点) |

- 状態は色だけで伝えない。状態ラベルは点と文字の組
- 点の形で「その状態にあるか」を分ける。塗りの点は済んだ・その状態にある、中抜きの点は「まだ」「無い」(未確認・暗号化が無効・未登録) だけに使う。済んだ状態を中抜きにすると「その状態ではない」と読まれる
  - 暗号化 確認済み・受信確認済み: 緑の塗り
  - サーバー名が古い: 琥珀の塗り
  - 移行済み: 青の塗り (完了の意味)
  - アーカイブ済み: 灰色の塗り。使われていない端末なので、ラベルも行・ページと同じく減色する
- アーカイブ済みの端末は、ラベルだけでなく画面全体で「使われていない」と分かるようにする
  - 一覧の行: 行ごと減色 (取り消し線は引かない)。状態ラベルは色を保つ
  - 詳細: 端末名・絵・節を減色し、ページ上部に帯「この端末はアーカイブ済み。通知の宛先に含まれない」(移行済みなら移行先の端末名とリンク)。操作は帯の「アーカイブから戻す」だけ (移行済みは移行先へのリンクだけ)
- 移行済みは行き先が分かる形 (「移行済み → <移行先の端末名>」) にする
- 黄色の上の文字は `--signal-ink` (紺)。黄色を文字色に使う時は light で `--signal-text` (濃い琥珀) に落とす

## 字

- 外部フォントは使わず、OS の UI フォント (San Francisco + ヒラギノ角ゴ)。iPhone で開いた時にアプリと地続きに見える
- 太さの対比で個性を出す: 画面の見出し 34px / 800、節の見出し 22px / 750、本文 16〜17px
- 等幅は照合・コピーする値だけ (device_id、鍵、サーバー名、宛先とタグの `k=v` の入力、端末情報の観察値、通知の param 名)
- 入力欄は 17px 以上 (iOS Safari がフォーカスで拡大しない大きさ)
- 文言は常体 (「送った」「確認済みになる」)。ボタンは起きることを動詞で書き、同じ操作は流れの中で同じ語にする

## 配置

- 幅は 3 段: 640px 未満は 1 列でダイアログは全画面、640〜959px は 1 列のまま最大 680px で中央寄せ (ダイアログは中央)、960px 以上は TOP が 1 列のまま最大 880px、詳細が 2 列 (左に知らせと状態、右にタグ・端末情報・アーカイブ)
- 一覧の行は、一覧の幅が 640px 以上 (TOP は 1 列なので viewport 672px 以上) なら状態ラベルを右の列に出す。container query は使わない (中身を描き直すと WebKit がスクロール位置を先頭へ戻すため)
- ダイアログは狭い幅 (640px 未満) では全画面にする。上下に隙間を残さず viewport いっぱい (safe-area 込み) にし、専用のページへ移ったように見せる: 上端に「戻る」と題のバー、中身だけがスクロールする。広い幅では中央に浮かべ、右上に ×
- ダイアログは必ず modal で開く (裏の画面は inert)。開閉は `src/client/dom.ts` の `setupDialogs` の 1 か所で、`commandfor` のボタンも JS で `showModal()` する。開いている間は裏の画面のスクロールを止める
- 角丸は階層で変える: 節・ダイアログ 22px、入力 14px、チップ 7px、ボタンはピル型

## 部品

`src/ui/components.ts` が HTML 文字列を返す関数として持ち、サーバのページ (`src/ui/pages.ts`) とブラウザの描き直し (`src/client/`) が同じ物を使う。差し込む値は `src/ui/html.ts` の `html` が既定でエスケープする。

| 部品 | 中身 |
|---|---|
| `appBar` / `backBar` | 画面の見出し (題・補足) / 一覧へ戻るリンク |
| `button` / `linkButton` / `opener` / `actions` | ボタンの種類 (primary / plain / quiet / danger / quiet-danger、small、block) / ダイアログを開くボタン (Invoker Commands) / ボタンの並び |
| `chip` / `chips` / `tagChips` | `k=v` のチップ。宛先の付け外しに使う時はボタン (当たり = 黄色の縁、宛先そのもの = 黄色の地) |
| `statusLabel` / `statuses` | 状態ラベル。何を出すかは `src/ui/device-status.ts` の `deviceStatuses`、点の塗り / 中抜きは tone で決まる |
| `rows` | 定義リストの行。値の右に小さな操作ボタン、下に注記、今回変わった行の強調 |
| `section` / `panel` / `alert` | 見出し付きの節 / 白い面 / 知らせ (warn / moved / archived。archived はアーカイブ済みの帯) |
| `field` / `textarea` / `switchRow` / `segmented` | フォームの行 / 入力欄 / スイッチ / 区切りボタン (level) |
| `dialog` | modal。狭い幅は全画面で左上に「戻る」、広い幅は中央で右上に ×。外側のクリックと Esc でも閉じる (開閉は `setupDialogs`) |
| `step` | 招待ページの段 (済み / 今 / 先) |
| `cryptoMeter` / `keyBox` | 暗号化の 3 段のうち今の段 / 伏せた鍵の欄 |
| `glyph` / `icon` | 端末の形の絵 (形は `glyphKind`: 招待ページの判定 → os タグ → UA の OS) / 線の絵 |
| `notificationPreview` | ロック画面の通知の見本 |

画面の塊 (端末の行、詳細の見出し・アーカイブ済みの帯・知らせ・状態の行、招待の行) は `src/ui/views.ts`。

## 動き・操作性

- 動きは人の操作に応える物だけ: ダイアログが少し下から現れる、畳んだ項目の矢印が回る、スイッチ。勝手に動くのは招待ページの「待っている」の点だけ
- `prefers-reduced-motion: reduce` では全部止める
- フォーカスは 3px の輪 (light は青、dark は黄色)。一覧の行はリンクの輪が行全体を囲む
- 鍵は詳細を開いただけでは出さない。暗号化のダイアログの「表示」で出し、閉じると伏せ直す。コピーは表示しなくてもできる

## 配り方

- ブラウザ側の TS (`src/client/`) は起動時に `Bun.build` でページごとに 1 本へ bundle し、`style.css` と一緒にメモリに持つ。ビルドの成果物はリポに置かない
- HTML の中の参照に内容の hash の `?v=` を付け、`Cache-Control: no-cache` + ETag で配る。bundle は import を持たないので、JS が版のずれた別ファイルを読むことは無い
